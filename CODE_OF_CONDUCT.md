# Code de conduite

Ce projet applique le [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En bref : on est bienveillant, on critique les idées et pas les personnes, on accueille les débutants et les non-développeurs (comptables, contrôleurs de gestion, RH… sont les premiers experts de ce projet).

Un comportement inacceptable se signale en privé au mainteneur, [@Hassen-Ti](https://github.com/Hassen-Ti).
